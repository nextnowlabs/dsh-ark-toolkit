Capability-focused workflows

Answer, transcribe, compare, generate.

One Skill activates three structured tools for the current Agent. Paste an image, ask a question, OCR visible text, compare screenshots, generate a picture, or read text out loud.

01 · Understand

Image Q&A and OCR

Pass one or more images to vision_glance with a question, ask for verbatim OCR, or zoom into a region so small text and icons become readable.

02 · Create

Seedream image generation

03 · Speak

ByteDance TTS voice synthesis

vision_speak turns text into MP3/OGG/PCM/WAV audio with the ByteDance Volcengine Speech TTS V3 service, delivered as a downloadable Artifact.

One runtime, explicit tools

Structured tools without a universal action switch.

Each capability has its own schema and structured result. The versioned Skill activates them for one Agent, while health and version administration stay in Web Settings instead of model context.

01

Understand images

Ask questions, OCR visible text verbatim, and compare multiple images in one call through the configured vision model.

02

Generate images

Seedream image generation with size and aspect-ratio control, delivered as a workspace Artifact.

03

Synthesize speech

ByteDance TTS with voice, format, speed, pitch, and emotion controls, delivered as an audio Artifact.

04

Ship real Artifacts

Generated images and audio carry stable descriptors for preview, download, or local open.

05

Protect credentials

DSH Credentials, path fencing, hard deadlines, redacted errors, and untrusted-visual-evidence handling keep data handling visible.

06

Run Web or Headless

Web adds cards and Settings; Headless receives the same complete tool semantics and structured results.

Quick start

Install one checkout into the profiles you use.

Requires DeepSeek Harness and a Volcengine Ark API key. No Python, no Chrome, no isolated runtime. Restart a running Web profile, then paste your key into Settings.

Full installation and security guide 
git clone https://github.com/nextnowlabs/dsh-ark-toolkit.git
PLUGIN="$PWD/dsh-ark-toolkit"

dsh plugin --profile web add "$PLUGIN"
dsh plugin --profile headless add "$PLUGIN"

dsh --profile web --dump-config | grep vision-toolkit
